Quick Integration

Integrate SMSMitra into your workflow in minutes.

1 Setup the Mobile App

Download SMSMitra APK on your Android device. Register and get your unique 4-character Access Code from the profile section.

2 The API Endpoint

Send a POST request to our gateway with your access code and message details.

Endpoint
POST http://silverapi.allysoftsolutions.com/smsmitra/v1/sms/trigger

3 Code Examples

Choose your preferred language to trigger the gateway.

cURL / Bash
curl -X POST http://silverapi.allysoftsolutions.com/smsmitra/v1/sms/trigger \ -H "Content-Type: application/json" \ -d '{ "deviceCode": "YOUR_CODE", "phoneNumber": "+919876543210", "message": "Hello from API!" }'
Python
import requests payload = { "deviceCode": "YOUR_CODE", "phoneNumber": "+919876543210", "message": "Hello from Python!" } response = requests.post( "http://silverapi.allysoftsolutions.com/smsmitra/v1/sms/trigger", json=payload ) print(response.json())
